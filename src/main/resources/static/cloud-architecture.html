6) Hinweise zur Cloud-URL Nutzung

  • Beim Start via Spring Boot: Öffne /cloud-architecture.html, /linelux-style.html oder /mobile.html.
  • Die hier gelisteten API-Pfade bauen auf den Controllern im Projekt auf und nutzen window.location.origin, damit sie lokal und in der Cloud funktionieren.
