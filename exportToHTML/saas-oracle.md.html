1    # SaaS Integration – Oracle Events & Node DSN
2    
3    This note summarizes the backend pieces referenced by the dashboard’s SaaS card.
4    
5    ## Azure Functions base
6    
7    Use your Azure Functions URL as BASE (example):
8    
9    ```
10   https://<deine-function>.azurewebsites.net
11   ```
12   
13   ### Quick tests
14   
15   ```js
16   fetch("https://<deine-function>.azurewebsites.net/health")
17     .then(r=>r.json()).then(console.log);
18   
19   fetch("https://<deine-function>.azurewebsites.net/infer",{
20     method: "POST",
21     headers: { 'Content-Type':'application/json' },
22     body: JSON.stringify({ pose:{x:0,y:0,theta:0}, prox:{front:2.0} })
23   }).then(r=>r.json()).then(console.log);
24   ```
25   
26   If your function requires a token, add `Authorization: Bearer <API_TOKEN>`.

30   ## Oracle table for events
31   
32   Example DDL (Oracle):
33   
34   ```sql
35   CREATE TABLE NUR_EVENTS (
36     ID        NUMBER GENERATED ALWAYS AS IDENTITY PRIMARY KEY,
37     TS_MS     NUMBER(13),
38     KIND      VARCHAR2(16),
39     PAYLOAD   CLOB
40   );
41   ```
42   
43   Example event payloads your `/events` endpoint may receive:
44   
45   ```json
46   { "type": "hal", "data": { "pose": {"x":0.2,"y":-0.1,"theta":0.7}, "prox": {"front":1.8} } }
47   ```
48   
49   ```json
50   { "pose": {"x":0.2,"y":-0.1,"theta":0.7}, "prox": {"front":1.8}, "vision": {"x":-0.15,"size":0.04} }
51   ```
52   
53   Persist as-is in PAYLOAD; store a millisecond timestamp in TS_MS.

57   ## Node oracledb – classic DSN
58   
59   ```js
60   const dsn = "(DESCRIPTION=(ADDRESS=(PROTOCOL=TCP)(HOST=<host>)(PORT=1521))\n"+
61               "(CONNECT_DATA=(SERVICE_NAME=<service>)))";
62   ```
63   
64   Use with `oracledb.getConnection({ user, password, connectString: dsn })`.

68   ## Infer response shape
69   
70   Example response from `/infer` your front-end expects:
71   
72   ```json
73   { "left": 0.46, "right": 0.72, "device": "cpu|cuda" }
74   ```
75   
76   The dashboard’s `saas-client.js` uses:
77   
78   ```js
79   const BASE = "https://<deine-function>.azurewebsites.net";
80   const HEAD = { "Content-Type":"application/json", "Authorization":"Bearer <API_TOKEN>" };
81   
82   async function inferAssist(state){
83     const r = await fetch(BASE+"/infer", { method:"POST", headers: HEAD, body: JSON.stringify(state) });
84     return r.json();
85   }
86   async function sendEvent(ev){
87     await fetch(BASE+"/events", { method:"POST", headers: HEAD, body: JSON.stringify(ev) });
88   }
89   ```
90   
91   These helpers are also exposed by the UI via the SaaS card.
