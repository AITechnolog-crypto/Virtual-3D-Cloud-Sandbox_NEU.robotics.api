1    # Framio API (Mock via Service Worker)
2    
3    This project provides a lightweight, client‑side mock of a "Framio" API implemented inside `src/main/resources/static/sw-mock-api.js`. It enables UI development without a backend.
4    
5    The mock requires a token with prefix `fio-u-` and supports a few simple endpoints.
6    
7    ## Endpoints
8    
9    Base: /api/framio
10   
11   - POST /token
12     - Body: `{ "token": "fio-u-..." }`
13     - Stores the token in the SW mock. Returns `{ ok: true, masked: "fio-u-…abc123" }`.
14     - Token must start with `fio-u-`.
15   
16   - GET /ping
17     - Returns `{ ok: true, time: ISO, hasToken: boolean }`.
18   
19   - GET /profile
20     - Requires token set. Returns a demo profile: `{ id, name, plan, token: masked }`.
21   
22   - POST /echo
23     - Requires token set. Returns: `{ ok: true, echo: <your body>, ts }`.
24   
25   - GET /frames?id=<id>
26     - Requires token set. Returns a mock frame object `{ id, title, vectors:[...] }` (cached by id during session).
27   
28   If a token is required but not present, the mock responds with HTTP 401 and `{ error: "Unauthorized" }`.
29   
30   ## Quick test (in browser console)
31   
32   ```js
33   const API = location.origin + '/api/framio';
34   
35   // 1) Set token (replace with your token)
36   await fetch(API + '/token', { method:'POST', headers:{'Content-Type':'application/json'}, body: JSON.stringify({ token: 'fio-u-7lHHhkbfOKsgodfRRril3aDfgT6F3noZ9KeC5ve8rNamlDVMyNYLrspKqp9YnwF5' }) }).then(r=>r.json());
37   
38   // 2) Ping
39   await fetch(API + '/ping').then(r=>r.json());
40   
41   // 3) Profile
42   await fetch(API + '/profile').then(r=>r.json());
43   
44   // 4) Echo
45   await fetch(API + '/echo', { method:'POST', headers:{'Content-Type':'application/json'}, body: JSON.stringify({ hello:'framio' }) }).then(r=>r.json());
46   
47   // 5) Frames
48   await fetch(API + '/frames?id=42').then(r=>r.json());
49   ```
50   
51   ## Notes
52   - These endpoints live entirely in the Service Worker and are meant for local preview (e.g., JetBrains 63342 or a simple static server). They are not persisted across full reloads or browser restarts.
53   - If you want to add a UI card later, call these endpoints from your page and show the results.
